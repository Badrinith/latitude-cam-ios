Latitude Cam / Shutter release / Five to pick from

Five ways to make the release feel like a release.

The current button is a white disc in a ring — correct, and indistinguishable from every other camera app. These five each borrow from a real release: a threaded cable socket, a brass soft release, an iris that closes as you press, a rim that doubles as the meter, and a frame counter. All are 88pt with the same hit target and the same haptic. Press any of them to see the state change.

01

Cable release

A machined collar around a threaded socket — the fitting a cable release screws into. The chrome plunger sits proud of the black knurled rim and dips when pressed.

04

Meter halo is the one I would build

It is the only one that makes the release carry information it does not carry today. The ring already exists and shows nothing; putting the meter on it means the exposure is readable without looking away from the frame — and it stays legible at 88pt, which the busier options do not.

03

Iris if you want people to remember it

The only direction where the button performs the thing it triggers. It is also the only one with a per-frame animation cost on the hot path, so it wants measuring against the preview before committing.

02

Soft release is the safest departure

Warm where everything else is warm, and the shape genuinely invites a thumb. My reservation is that a coloured filled circle reads as a state — people may look for it to be "on".
